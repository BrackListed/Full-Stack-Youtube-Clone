# [ ▶︎ ] Youtube Clone 🔴
A youtube clone website that imitates the core features of the actual youtube website, including file uploading, sharing, subscriptions, etc.

## Tech Stack

* **Frontend:** React, Tailwind CSS
* **Backend:** Node.js, Express.js
* **Database:** PostgreSQL (with relational queries for likes, dislikes, and comments)
* **Media Storage & Processing:** Cloudinary, Multer

---

## Core Features

* **Video Management & Uploads:** Seamless media handling via Multer middleware paired with Cloudinary cloud storage.
* **Interactive Social Graph:** Relational database architecture tracking video likes, dislikes, and dynamic comment threads.
* **Creator Studio & Dashboard:** Centralized analytics and content management interface for creators.
* **Subscriptions & Feeds:** Dynamic subscription management and personalized content delivery.
